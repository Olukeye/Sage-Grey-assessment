# Assessments

Two independent projects, each with its own README, tests and run instructions.

| Folder | What | Stack |
|---|---|---|
| [`frontend/`](frontend/README.md) | Star Wars character browser (SWAPI) | React, TypeScript, Vite, SCSS |
| [`backend/`](backend/README.md) | Wallet API: accounts, funding, transfers, withdrawals, full auth | Node, TypeScript, Express, Knex, PostgreSQL |

The backend's technical design document is at [`backend/docs/DESIGN.md`](backend/docs/DESIGN.md).

Each folder is meant to be its own GitHub repository (or push them together as a monorepo).
